# Roles & Badges

Roles in RBWR represent a player's experience level and grant operational privileges. Roles are earned from accumulated points across both U1 and U2 combined.

## Roles

| Role | Typical experience | Privileges / unlocks |
|------|--------------------|-----------------------|
| **Verified Player** | Default | Standard access |
| **Junior Operator** | "You've been hired!" badge | Access to Aux Hall and EDG Building; LPCI and RCIC control; Reactor SCRAM authority |
| **Operator** | "Promoted!" badge | Access to U2 TCR, FWP Pit, U2 MCR (U2 MCR unlocks at **5000 U1 points**); U2 manual control locking; in U1, the synchroscope must be aligned for the GEN. BREAKER to function |
| **Senior Operator** | Experienced | Master Acknowledge authority. |
| **Junior Supervisor** | "Supervising Others" badge | Supervisor Room access; spawn with a Cell Phone |
| **Supervisor** | Experienced | Demand Changing Panel access |
| **Senior Supervisor** | Experienced | PA (intercom) system access; Unit Interlock access |
| **Junior Inspector** | "Safety Inspector" badge | Inspector Office access |
| **Inspector** | Very experienced | Inspector Tablet access (perform Inspections) |
| **Senior Inspector** | Very experienced | Plant Evacuation authority |
| **Chief Inspector** | "The Chief" badge | Status-only. People bow in awe. |
| **Plant Manager** | "It's Lonely at the Top..." badge | Plant Manager Office access. Requires ~957 hours of play at maximum 2.9 pts/sec (39 days, 21 hours, 51 minutes). |

```note
Roles are inclusive: if you reach Senior Supervisor you keep all earlier privileges. Operator's synchroscope requirement applies to the person at the turbine panel; a lower-ranked crewmate can press the breaker on their behalf.
```

## Badges

| Badge | Earn it by |
|-------|------------|
| Met the Creator | Be in a server with DelfinoDelphis |
| Manually Synchronized | Sync U2 turbine manually (no autocontrol) |
| Recovered an Off-the-rails Offsite (was: Better than in Fukushima) | Safely shut down during an offsite event |
| Master of Malfunctions | Tag all malfunctions correctly and call maintenance |
| Shutdown for Maintenance (was: You are so cool) | Complete a maintenance-shutdown event |

| Unit 02 Manual Startup | Start U2 with zero autocontrols |
| Nuclear Plumber | Shutdown the reactor, call the leak check, have one or more leaks found |
| Turbine Rundown Success! (was: Better than Chernobyl) | Successfully run the safety test on the **RBMK** reactor type |
| Game Inside a Game | Play Pong on the TCR computer (press D) |
| Irradiated | Receive a dose above safety limits and get scanned at the turbine hall entrance |
| Poured Oil on Troubled Waters | Repair a U2 turbine oil leak |
| Blunt Force Trauma | Jump down the shaft in the Reactor Hall (fall damage) |
| You've been Thunderstruck! | Touch any outer cable in the [Switchyard](#) (instant kill) |

| You've Been Promoted! | Earn Operator rank |

| Safety Inspector | Earn Junior Inspector rank |

| It's Lonely at the Top... | Earn Plant Manager rank |

```nerd
Plant Manager rarity is essentially zero. At the documented maximum earn rate (2.9 pts/sec from dual full-manual operation with inspector tablet running), reaching it takes nearly **40 days of continuous play**, assuming you're never bottlenecked by demand bands, malfunctions, or sleep.
```
